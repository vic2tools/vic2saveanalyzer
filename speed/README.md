# Speeding up the scanner: how to run a session

Start each new session with:

    Read speed/CONTEXT.md and speed/STATUS.md in ~/vic2saveanalyzer, then do
    the next task file in speed/ that STATUS.md says is not done.

Each NN-*.md file is sized for one session. STATUS.md is the hand-off
between sessions. The scripts need `speed/local.env` (not committed); see
CONTEXT.md.
